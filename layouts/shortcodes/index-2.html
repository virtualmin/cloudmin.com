A short path to a running guest

Install Cloudmin, pick an image and click Create. The installer sets up libvirt, a network, storage and firmware, and checks that the host is ready.

Built on libvirt, not around it

Cloudmin never builds raw QEMU command lines or scrapes virsh output. Libvirt stays the source of truth, so other tools and your own scripts see the same machines.

Safe by design

Creation, cloning, backups and restores run as jobs that survive an interruption. Downloads, disk inspection and consoles run without root, so a bad image cannot take the host with it.

Virtualmin inside every guest

Choose a Virtualmin GPL or Pro template. Cloudmin installs the hosting stack inside the new machine and opens its Webmin through the host, even behind NAT.

Open source core, unlimited guests

Cloudmin GPL manages one host with as many virtual machines as it can carry. Pro adds SSH key management, setup scripts, cloud backups and image capture, with tenancy to follow. Cloudmin Connect will bring many hosts together.

The same API for people and scripts

The web interface, the command line and remote clients use one JSON API with signed requests, Webmin permissions and audit logging. Automate Cloudmin the way you already automate Virtualmin.
